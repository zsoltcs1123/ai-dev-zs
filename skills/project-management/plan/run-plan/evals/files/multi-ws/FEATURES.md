# Feature Map

## Workstreams

| Code | Workstream | Features |
| ---- | ---------- | -------- |
| COR  | Core Engine | 4 |
| CLI  | CLI App | 3 |
| IDE  | IDE Extension | 3 |

## COR — Core Engine

| Code  | Feature               | Goal                                                                                    |
| ----- | --------------------- | --------------------------------------------------------------------------------------- |
| [COR-1](COR/COR-1/COR-1.md) | Task Management       | Enable teams to create, assign, prioritize, and track tasks as the foundation of all project workflows |
| [COR-2](COR/COR-2/COR-2.md) | Dependency Tracking   | Make inter-task dependencies explicit so conflicts and blockers surface at planning time, not during execution |
| [COR-3](COR/COR-3/COR-3.md) | Status Inference      | Automatically detect task status from Git activity so the project state stays current without manual updates |
| [COR-4](COR/COR-4/COR-4.md) | Notification Dispatch | Alert team members to blocked tasks and dependency changes so issues are addressed before they cascade |

## CLI — CLI App

| Code  | Feature                | Goal                                                                                    |
| ----- | ---------------------- | --------------------------------------------------------------------------------------- |
| [CLI-1](CLI/CLI-1/CLI-1.md) | Task Commands          | Provide terminal commands for the full task lifecycle so developers manage work without leaving the terminal |
| [CLI-2](CLI/CLI-2/CLI-2.md) | Board Views            | Render kanban and list views in the terminal so teams visualize project state at a glance |
| [CLI-3](CLI/CLI-3/CLI-3.md) | Team Dashboard         | Display a unified view of all team members' task status so the whole team has shared visibility |

## IDE — IDE Extension

| Code  | Feature                 | Goal                                                                                    |
| ----- | ----------------------- | --------------------------------------------------------------------------------------- |
| [IDE-1](IDE/IDE-1/IDE-1.md) | Sidebar Views           | Show board and task detail in the VS Code sidebar so developers access project state without context-switching |
| [IDE-2](IDE/IDE-2/IDE-2.md) | Inline Notifications    | Surface task alerts and dependency changes directly in the IDE so developers respond without checking external tools |
| [IDE-3](IDE/IDE-3/IDE-3.md) | Status Bar Integration  | Display current task status in the VS Code status bar so developers always know what they're working on |

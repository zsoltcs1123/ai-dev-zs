# Capture Idea

Distill freeform input into concise bullet points that capture the essence of an idea.

## When to Use

- User shares a new idea or brain dump
- An idea emerges from conversation and needs recording
- User wants to capture something for later refinement

## Input

Freeform text — keywords, sentence fragments, a wall of text, or a conversation where an idea surfaced.

## Procedure

1. Listen to the input. Don't interrogate — absorb.
2. Distill to key points. If the idea came from a longer conversation, reduce to essentials rather than transcribing.
3. Present as simple bullet points in chat. Keep it raw — fragments are fine.
4. If the user asks, write to a file. Otherwise, chat-only.

## Scope

This skill records, nothing more. Do NOT explore feasibility, tech choices, structure, or next steps unless the user explicitly asks. If the idea needs exploration, suggest `vibe-plan`.

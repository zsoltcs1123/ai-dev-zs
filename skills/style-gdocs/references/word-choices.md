# Word choices

High-impact substitutions from the [Google developer documentation word list](https://developers.google.com/style/word-list).

| Avoid | Prefer |
| --- | --- |
| just | Delete it, or use *only* / *instead* if the meaning needs it |
| simple, simply, easy, easily | Delete it |
| please, please note | Delete it in instructions. Use *please* only when asking for permission or forgiveness |
| in order to | *to*, unless *to* is ambiguous |
| allows you to, enables you to | *lets you* |
| utilize | *use* (keep *utilization* for resource quantity) |
| leverage | A concrete verb: *use*, *apply*, *build on* |
| currently, as of this writing, at present, at this time, now (for features) | Delete it. State the fact. |
| and/or | *and* or *or*, or rewrite |
| click here, this document (as link text) | The page title or a descriptive phrase |
| aka | *also known as*, or put the synonym in parentheses |
| agnostic | A precise term: *platform-independent* |
| actionable | Delete it, or *that you can act on* / *useful* |
| etc., and so on | Introduce the list as non-exhaustive (*such as*, *like*) |
| since (meaning because) | *because* |
| as (meaning because) | *because* |
| should, should be | *must* for a requirement, *can* for an option, or rewrite |
| may | *can* (ability or permission) or *might* (uncertain outcome) |
| let's | Address *you*, or use the imperative |
| click on | *click* |
| above / below (in a document or UI) | *earlier*, *preceding*, *following*, or name the thing |
| slave | *replica*, *worker*, or a domain-accurate pair |
| master (paired with slave) | *primary*, *leader*, or a domain-accurate pair |

*Enable* is fine for turning a feature on. For making something possible, use *lets you*.

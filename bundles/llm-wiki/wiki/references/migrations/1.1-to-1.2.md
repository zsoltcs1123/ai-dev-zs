# Migrate 1.1 to 1.2: hub-only index

## Preconditions

The wiki `scaffold` value is `1.1`.

## Steps

1. Open `wiki/index.md` and show the user the planned diff before you save.
2. Remove any **Sources** section that lists routine source pages. Source inventory stays under `wiki/sources/{author}/`.
3. Keep hub sections only: **Concepts**, **Entities**, **Syntheses**, and **Reference Corpora**. Add empty placeholders when a section is missing.
4. Align the intro with the current scaffold `wiki/index.md` (curated hub, not a source catalog).
5. Set `scaffold` to `1.2` in `.wiki-root.yaml`.

## Verification

- `wiki/index.md` has no `## Sources` section that lists routine source pages.
- Hub sections for concepts, entities, syntheses, and reference corpora are present.
- After migrate, do not list routine source pages in the index (operate guardrail).

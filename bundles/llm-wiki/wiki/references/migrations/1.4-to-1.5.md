# Migrate 1.4 to 1.5: log newest first

## Preconditions

`scaffold` is `1.4`.

## Steps

1. Tier A additive sync when the dry-run lists missing scaffold paths ([migrate.md](../commands/migrate.md)).
2. Open `wiki/log.md`. Show the planned diff before save.
3. Ensure the line `Newest entries first. Do not edit or remove prior entries.` appears directly under `# Wiki Log` (add if missing).
4. Reverse entry order when the file is oldest-first: top `## [date]` is earlier than the next. Keep each `##` block and its bullets intact; move whole blocks only. Already newest-first: skip reorder.
5. Set `scaffold` to `1.5` in `.wiki-root.yaml`.

Conventions: [log.md](../log.md).

## Verification

- Convention line present under `# Wiki Log`.
- Dated `##` headings run newest → oldest.
- Entry text unchanged aside from reorder and the convention line.

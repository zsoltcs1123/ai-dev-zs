# Migrate 1.0 to 1.1: wiki root marker

## Preconditions

The wiki `scaffold` value is `1.0`, or `.wiki-root.yaml` has no `scaffold` key.

## Steps

1. If `.wiki-root.yaml` is missing, create it. Set `slug` from the directory name or your existing convention. Set `name` to a human label or repeat the slug.
2. Confirm `slug` and `name` are present. When this playbook finishes, set `scaffold` to `1.1`.
3. In a multi-wiki host, add a row to `wikis/AGENTS.md` if one is missing.
4. Optionally copy [WIKI-SYSTEM.md](../../../../WIKI-SYSTEM.md) to `wikis/WIKI-SYSTEM.md`.

## Verification

- `.wiki-root.yaml` exists and has a valid `slug`.
- `wiki/index.md` and `raw/sources/`, `raw/notes/`, and `raw/reference/` are unchanged.

## Log and commit

- `wiki/log.md`: `migrate | backfill wiki root marker (1.0 → 1.1)`
- Commit subject: `wiki(<slug>) migrate: backfill wiki root marker`
